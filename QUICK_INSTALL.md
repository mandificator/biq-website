# 🚀 Instalare Rapidă pe Laptop

## 📋 Pași Simpli:

### 1. Creează folderul proiectului:
```bash
mkdir biq-dashboard
cd biq-dashboard
```

### 2. Copiază fișierul `package.json` din acest proiect

### 3. Instalează toate dependințele automat:
```bash
npm install
```

### 4. Copiază toate fișierele sursă din `src/` și `public/`

### 5. Copiază fișierele de configurare:
- `vite.config.ts`
- `tsconfig.json` 
- `tsconfig.app.json`
- `tsconfig.node.json`
- `tailwind.config.js`
- `tailwind.css`
- `index.html`

### 6. Pornește aplicația:
```bash
npm run dev
```

## 🌐 De unde vin dependințele?

**npm** (Node Package Manager) descarcă automat toate pachetele de pe **npmjs.com**:
- `react` - Librăria React
- `chart.js` - Pentru grafice
- `date-fns` - Pentru manipularea datelor
- `tailwindcss` - Pentru styling
- Și toate celelalte...

## ✅ Rezultat:

Dashboard complet funcțional cu:
- 📊 Analytics în timp real
- 📈 Grafice interactive
- 👥 Tabel useri cu filtrare
- 🎨 Dark/Light mode

**Nu trebuie să descarci manual nimic** - `npm install` face totul automat!
